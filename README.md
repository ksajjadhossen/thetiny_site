A pixel-perfect, fully responsive React landing page clone of [The Tiny Site](https://thetiny.site/), developed as part of the **Front-End Developer Internship Assignment** for **Bangla Puzzle Limited**.

The project focuses on accurately recreating the original website's visual design, layout, typography, and responsive behavior while maintaining clean, reusable, and well-structured React components.

## 🛠️ Getting Started & Local Installation

Want to explore the project, run it locally, or build upon it? Follow these steps to get your own local copy running.

### Prerequisites

Make sure you have the following installed:

- **Node.js:** Version 16 or higher
- **npm:** Included with Node.js
- **Git:** For cloning the repository
- **Code Editor:** VS Code or your preferred editor

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/ksajjadhossen/thetiny_site.git
```

### 2. Navigate to the Project Directory

```bash
cd thetiny_site
```

### 3. Install Dependencies

Install all the required packages:

```bash
npm install
```

### 4. Start the Development Server

Run the following command:

```bash
npm run dev
```

Once the server starts, open the local URL displayed in your terminal. By default, Vite usually runs at:

```text
http://localhost:5173/
```

**That's it!** Your local copy of The Tiny Site is now up and running.

### 5. Customize & Explore

You are welcome to explore and modify the project:

- Update React components to customize the interface.
- Modify Tailwind CSS classes to adjust layouts and styling.
- Experiment with the existing components and page structure.
- Take advantage of Vite's Hot Module Replacement (HMR) to see changes instantly.

## 📦 Production Build

To generate an optimized production-ready build, execute:

```bash

```

To preview the production build locally:

```bash
npm run preview
```

The optimized output will be generated inside the `dist/` directory.

